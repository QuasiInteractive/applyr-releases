# Applyr

**An honest job-application assistant for Windows**, by [Elyra Software](https://quasi-interactive.com/elyra), a Quasi Interactive company.

**[Download the latest installer from Releases →](../../releases/latest)** · Early access

## What it does

- **Finds roles near you** and screens each ad against the things that would actually disqualify you.
- **Writes an application that names its own gaps.** It never puts a claim in your mouth that you did not make.
- **Fills in the real application form**, then **stops at the submit button** so a person presses it. Applyr never submits on your behalf.
- **Pico**, a built-in companion, explains every step and answers questions. Pico never makes up a fact about you.
